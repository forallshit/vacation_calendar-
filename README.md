# Бот-напоминалка о прививках

Простой Telegram-бот: родитель добавляет ребёнка (имя + дата рождения),
бот сам считает график прививок по национальному календарю РФ
и раз в день присылает напоминания (за 3 дня и в день прививки).

## Что внутри

- `bot.py` — команды бота (/start, /add, /list) и диалог добавления ребёнка
- `vaccines.py` — сам календарь прививок (даты в днях от рождения)
- `database.py` — хранение данных (файл `privivki_bot.db`, создаётся сам)
- `scheduler.py` — ежедневная проверка и рассылка напоминаний
- `requirements.txt` — список нужных библиотек

## Как запустить локально (для проверки на своём компьютере)

### 1. Установи Python
Если ещё нет — скачай с python.org (версия 3.10 или новее). При установке
на Windows обязательно поставь галочку "Add Python to PATH".

### 2. Получи токен бота
1. В Telegram найди **@BotFather**
2. Напиши `/newbot`, следуй инструкциям (имя бота, потом username, обязательно
   заканчивается на `bot`)
3. Он даст токен вида `123456789:AAH...` — скопируй его

### 3. Установи библиотеки
Открой терминал (командную строку) в папке с файлами бота и введи:

```
pip install -r requirements.txt
```

### 4. Вставь токен
Открой файл `bot.py`, найди строку:

```python
BOT_TOKEN = os.getenv("BOT_TOKEN", "ВСТАВЬ_СЮДА_СВОЙ_ТОКЕН")
```

Замени `ВСТАВЬ_СЮДА_СВОЙ_ТОКЕН` на свой токен от BotFather (кавычки оставь).

### 5. Запусти
```
python bot.py
```

Если в терминале появилось "Бот запущен" — всё работает. Иди в Telegram,
найди своего бота по username, нажми /start.

## Как проверить, что всё работает

1. Напиши боту `/add`
2. Введи любое имя, потом дату в формате ДД.ММ.ГГГГ
3. Напиши `/list` — должен показать ближайшие прививки с датами

## Как сделать бота доступным 24/7 (не только когда твой компьютер включён)

Локально бот работает, только пока запущен на твоём компьютере. Чтобы он
отвечал людям круглосуточно, его нужно "задеплоить" — разместить на сервере.
Самый простой вариант для новичка:

- **Railway.app** — загружаешь туда эту папку с кодом (через GitHub), он сам
  запускает бота и держит его включённым. Есть бесплатный лимит для старта.
- **Render.com** — похожий сервис, тоже с бесплатным тарифом.

Оба варианта не требуют настройки серверов руками — просто подключаешь
GitHub-репозиторий с этим кодом, задаёшь переменную окружения `BOT_TOKEN`
в настройках сервиса (вместо того чтобы вписывать токен прямо в файл —
так безопаснее), и сервис сам всё запускает.

## Что дальше стоит доработать

- **Сверить календарь прививок** в `vaccines.py` с актуальным приказом
  Минздрава — я заложил основные пункты нацкалендаря, но перед реальным
  запуском для пользователей это нужно перепроверить у педиатра/на
  официальном источнике (могут быть изменения)
- **Удаление/редактирование ребёнка** — сейчас можно только добавлять
- **Часовой пояс** — сейчас напоминания шлются по времени сервера,
  для расширения на разные регионы стоит учитывать часовой пояс пользователя
- **Оплата/подписка** — когда будешь добавлять монетизацию, у Telegram
  есть встроенный Payments API
